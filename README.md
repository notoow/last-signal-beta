# LAST SIGNAL · Web beta

[Play in your browser](https://notoow.github.io/last-signal-beta/) · [Report a bug](https://notoow.github.io/last-signal-beta/beta/feedback.html)

Version 0.45.0. Development beta, best played with a desktop keyboard and mouse. Saves stay in this browser; clearing site data removes saves. No account is required to play. GitHub sign-in is required to submit a public issue. Do not include personal information in reports.

This repository contains the browser distribution only. Development history, desktop packages, tests and private documents are not published here. Browser JavaScript and assets are downloadable.
